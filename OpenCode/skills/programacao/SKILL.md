## 💻 Programação
- Desenvolvimento front-end com foco em segurança e responsividade:
    -- Principais ferramentas: Angular e typescript 
    -- Ferramentas menos usadas: Astro e React Native 
- Desenvolvimento backend com foco em APIs REST: 
    -- Principais ferramentas: Java e Node.js 
- Estruturas de dados e algoritmos (nível intermediário)
- Código limpo (Clean Code) e boas práticas
- Programação orientada a objetos (OOP)
- Leitura e uso de documentações oficiais
- Escrita de código simples, legível e bem estruturado
- Debugging e resolução de problemas

## 🐧 Linux
- Uso diário de Linux como ambiente de desenvolvimento e automação com terminal
- Comandos avançados de terminal (bash, fish)
- Shell scripting básico/intermediário
- Gerenciamento de processos e sistema
- Configuração de ambiente (SSH, variáveis, etc.)
- Automação com scripts

## ⚙️ Ferramentas
- Git & GitHub (versionamento)
- Docker (noções práticas)
- VS Code / Neovim
- Banco de dados (PostgreSQL / MySQL)

## 🧠 Filosofia de Código
- Prioridade em código limpo e legível
- Preferência por soluções simples e bem explicadas
- Uso constante de documentação oficial
- Escrita de código pensando em manutenção futura

## ⚡ Diretrizes de Interação
- Fornecer explicações objetivas e de fácil compreensão
- Analisar o contexto antes de realizar modificações
- Fazer perguntas quando houver ambiguidade ou múltiplas abordagens possíveis
- Sugerir soluções criativas quando solicitado
- Garantir segurança ao lidar com dados sensíveis
